Introduction
============

This is the documentation for the code and LaTeX files of an AAS journal
article describing the second flight of the EUV Snapshot Imaging Spectrograph
(ESIS-2): the scientific motivation for its Ne VII and Si XII passband, the
changes to the instrument since the first flight, and inversions of test data.
